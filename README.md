# brd-gen-
A multi-modal AI agent that turns scattered calls, emails, images and
PDFs into traceable Business Requirement Documents.

## Problem statement
Scalable multi-modal AI system on Google Gemini and Google Cloud for
context-aware, explainable decisions.

## Solution
Ingest -> Extract (Gemini) -> Consolidate -> Generate BRD, with a source
on every requirement and conflicts flagged for human review.

## Tech stack
Gemini (Vertex AI), Cloud Storage, BigQuery, Python, Streamlit

## Status
Planning complete. Application code will be written during the
hackathon.
